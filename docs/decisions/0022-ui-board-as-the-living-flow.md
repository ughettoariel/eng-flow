# A UI board holds the product's flows

A Figma or Miro board, named in the project's config, holds the product's screens as flows with their states and is kept current. A PR that changes a UI links the flow or a capture of what changed; an animation goes in the PR description and on the board. When a change reaches screens outside its ticket, a new task updates them on the board. There is no evidence branch and no capture tooling: the agent verifies in the running app and reports what it saw.

## Status

Accepted as direction. Updating the board is not automated yet.
